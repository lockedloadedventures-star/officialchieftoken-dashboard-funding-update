## Daily Routine (Takes 30 min)

**Morning (7-8am)**
```
1. Check overnight metrics (2 min)
   - Uniswap volume + price
   - Gumroad enrollments
   - Email growth
2. Post today's content (5 min)
   - Use template from battle card
   - Post to Instagram + Stories
   - Pin to top
3. Plan engagement (3 min)
   - Identify 5 top comments to reply to
   - List potential DMs to send
```

**Midday (12-1pm)**
```
4. Engage community (15 min)
   - Reply to comments (value + CTA)
   - Respond to DMs (use templates)
   - Repost community content
5. Check ad performance (3 min)
   - Meta Ads Manager: CPA, ROAS, CTR
   - If performing: boost
   - If underperforming: kill + pivot
```

**Evening (6-7pm)**
```
6. Log metrics (5 min)
   - Daily tracking sheet
   - Volume, holders, enrollments, email growth
7. Community pulse check (5 min)
   - Discord sentiment
   - Any support issues?
   - Reply to 3 most active members
8. Tomorrow's prep (3 min)
   - Review tomorrow's content
   - Prep Discord announcement
```
