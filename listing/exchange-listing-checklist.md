# Exchange Listing Checklist (CHIEF)

## Required before any listing

- Deploy token to a supported mainnet (Ethereum and/or Base).
- Verify source code on block explorer.
- Confirm ownership model (owner wallet, multisig, or renounced ownership).
- Publish project website and token documentation.
- Prepare official social links and support contact.
- Prepare token logo files (256x256 and 1024x1024 PNG).
- Decide circulating supply and treasury disclosures.

## Coinbase Asset Hub

- Create issuer account at Coinbase Asset Hub.
- Submit contract address (mainnet only), symbol, decimals, and project links.
- Provide legal and compliance information requested by Coinbase.
- Provide team/issuer verification documents when requested.

## CoinGecko and CoinMarketCap

- Submit token metadata form with:
  - Contract address
  - Name/symbol/decimals
  - Explorer link
  - Website + socials
  - Market pair(s)
- Ensure active market pairs with real liquidity exist before submission.

## DEX market launch

- Create CHIEF/ETH or CHIEF/USDC pool on chosen DEX.
- Add initial liquidity from treasury wallet.
- Lock LP if desired and publish lock details.
- Share pair address and chart link publicly.

## Post-launch monitoring

- Track holder distribution and concentration risk.
- Monitor liquidity depth and slippage.
- Publish contract and treasury transparency updates.
